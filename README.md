# Logic Building with Java

A step-by-step journey from basic conditions to intermediate problem solving using Java—with solutions, explanations, dry runs, and learning notes.

I’m building this repository as I learn. My goal is to document how I approach problems and create a clear path that other learners can follow.

## Who Is This For?

Learners who know basic Java syntax and want to strengthen their problem-solving skills before moving deeper into Data Structures and Algorithms.

You should be familiar with variables, data types, operators, input/output, and running a Java program.

## Learning Roadmap

Follow the phases in order. Within each phase, work through its levels or categories sequentially.

| Phase | Topic | What You Will Practice |
| --- | --- | --- |
| 1 | Conditional Thinking | Making decisions using comparisons, if-else, nested conditions, and Boolean logic |
| 2 | Looping and Patterns | Repetition, digit manipulation, number problems, nested loops, and patterns |
| 3 | Recursion | Breaking problems into smaller versions, identifying base cases, and tracing calls |
| 4 | Basic Arrays | Traversing, searching, counting, transforming, and comparing collections of values |
| 5 | Strings | Analyzing characters, reversing text, manipulating words, and finding patterns |
| 6 | Mixed Logical Challenges | Combining conditions, loops, recursion, arrays, and strings |

## How to Follow This Repository

For each problem:

1. Read the question and identify its inputs and expected output.
2. Try a small example on paper.
3. Write your approach in plain language.
4. Implement your solution in Java.
5. Check normal inputs and edge cases.
6. Compare your approach with the solution and notes.
7. Try solving it again later without looking at the code.

The goal is to understand why a solution works and apply that reasoning to new problems.

## Running a Solution

Install a Java Development Kit (JDK), then open a terminal in the folder containing the solution.

For a file named `Main.java` with a class named `Main`:

```bash
javac Main.java
java Main
```

If a solution uses a different filename and class name, use those names instead. Run each problem from its own folder.
